# PRD.md — Gustiansyah Portfolio Website

## 1. Product Overview

This website is a personal professional portfolio and product-release style landing page for **Gustiansyah**.

The website must not feel like a generic CV portfolio, freelancer template, or random collection of design samples. It should feel like a modern AI/product/company-style website that presents Gustiansyah as an independent creative partner with strong direction, taste, research-driven thinking, imagination, and AI-assisted production capability.

The website should communicate that Gustiansyah can help modern brands create product visuals, AI videos, ecommerce campaigns, UGC concepts, product display content, brand content, AI-assisted workflows, and creative production outputs.

This website is not positioning Gustiansyah as a large agency or fake studio with a big team. The positioning must remain personal, credible, grounded, and strong.

---

## 2. Core Positioning

Final positioning:

**Independent AI production partner for data-informed product visuals, ecommerce campaigns, and brand content.**

This means:

- Gustiansyah works independently.
- Gustiansyah uses AI tools, research, references, creative direction, and production workflows to create brand/product outputs.
- AI is used as a production tool, not claimed as a fake proprietary platform.
- The work is informed by data, references, product context, market signals, and visual research.
- The final output is shaped through imagination, intuition, experience, taste, and creative execution.
- The website should build authority and bargaining power without overclaiming.

Avoid positioning the website as:

- A big agency.
- A fake large AI SaaS company.
- A generic personal CV.
- A random AI experiment gallery.
- A fashion designer portfolio.
- A developer portfolio.
- A WordPress/PHP service page.

## 14. Creative Finder

Creative Finder appears after the Core Hero Text.

Creative Finder is the main interactive input of the homepage.

It should feel inspired by modern AI interfaces such as OpenAI, Gemini, Claude, and other assistant/product interfaces, but it must not be decorative only.

### Placeholder Prompts

Placeholder prompts can rotate with subtle animation.

Example prompts:

- “How can I help you today?”
- “What can we build for your product?”
- “Turn my product into a campaign.”
- “Find visuals for an eyewear brand.”
- “Create ecommerce content.”
- “Build a product launch story.”
- “Explore AI video ideas.”
- “Create a lookbook from product photos.”

### Functional Behavior

V1 does not need paid AI API.

V1 must use a hardcoded dictionary array for intent-to-route mapping.

Required file name:

`creativeFinderDictionary.ts`

Required file path:

`src/data/creativeFinderDictionary.ts`

or the closest existing project convention.

Forbidden in V1:

- AI API
- Gemini API
- OpenAI API
- Algolia
- ElasticSearch
- vector database
- external search library
- semantic embedding search
- backend database search

Required logic:

`input → normalize lowercase → match keywords → score matches → return route suggestions → fallback to custom brief / Hire Me`

### No Result State

If no exact match exists, the website must not show a dead end.

Show a helpful result such as:

**“No exact library item yet, but this can be built as a custom creative direction.”**

Then offer paths:

- Explore related capabilities.
- View similar work.
- View Creative Library.
- Hire Me through WhatsApp.

## 24. Visual Direction — White-based Premium

The website must utilize a clean, white-based interface.

The UI should feel:

- premium
- restrained
- intentional
- white-based with gallery/editorial feel
- expansive whitespace inspired by AKQA / Apple / Behance / Pinterest clarity
- harmonized
- confident
- not too decorative
- not like a generic CV template

### Background

Use clean, premium white or soft off-white canvas.

Recommended canvas values:

- `#FFFFFF`
- `#FAFAFA`
- `#F7F8FA`
- `#F6F6F4`

Do not create a dark mode or dark neutral background for V1.

### Typography

Use crisp typography with high contrast:

- deep grey
- soft black
- charcoal text on the white canvas

Recommended text values:

- `#111111`
- `#1E1E1E`
- `#333333`
- `#555555`

Avoid pure black everywhere if it creates harshness. Use visual hierarchy.

### Harmonization Rule

The website must not look like screenshots from different websites stitched together.

All sections must share one unified design language.

White-based does not mean boring. The work provides the color, texture, contrast, and visual power.
